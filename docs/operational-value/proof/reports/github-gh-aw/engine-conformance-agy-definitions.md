## How to read the timeline

- Observations begin at workflow adoption on `2026-10-08`.
- No comparable pre-adoption evidence is available. Complete adjacent post-adoption periods may still show recent change, but not change relative to adoption.
- Each dot is one immutable observation. Missing evidence is omitted, never treated as zero.
- Execution activity is diagnostic only. It does not prove repository value.
- Recent change compares the immediately preceding equal-duration period, not lifetime movement. Interval windows must abut without overlap; snapshot values compare cutoff states.
- Two observations show observed change, not a sustained trend, statistical anomaly or target attainment. Unknown coverage, gaps and provisional evidence make comparison unavailable.
- Adoption comparison is separate. Stable-but-bad outcomes are not healthy merely because their latest delta is zero; workload-mix changes can explain aggregate movement.

## What was measured

**Goal:** Verify experimental Agy production authentication, AWF, native MCP and safe-output behavior.

**Accepted outcome:** Partial facet: the five shared protected host assertions establish observed schema, file, inference, shell/environment and tool-round-trip behavior. Native MCP transport, inference accounting and staged native safe-output extensions are separate and not established by these five cases.

### Core behavioral conformance

- **What it tells you:** Host-verified core conformance. This is a `primary` measure.
- **Native measurement formula:** `100 * passed stable behavioral cases / assessed stable behavioral cases in complete admitted assessments`
- **Unit:** `percent`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

### Independently verified cases

- **What it tells you:** Independently verified behavioral cases. This is a `diagnostic` measure.
- **Native measurement formula:** `count actual independently asserted stable behavioral cases, whether passing or failing; not successful runs`
- **Unit:** `probes`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

### Observed core behavior proofs

- **What it tells you:** Observed independently proven core behaviors. This is a `diagnostic` measure.
- **Native measurement formula:** `count protected host behavioral assertions that demonstrably pass; preserve this observed subtotal when other attempts are unknown`
- **Unit:** `probes`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

## Evidence rules

- **Repository:** `github/gh-aw`
- **Evidence population:** Five stable behavioral probe cases per actual conformance assessment on the frozen mainline history.
- **Collection:** Replay normalized bounded Actions attempt evidence. Acquisition and host-script verification happen separately, never per evaluation window.
- **Observation window:** 7 days, sampled every 7 days
- **Maturation delay:** 0 days
- **Filters:** `Only protected host assertions from an approved immutable checker script are accepted.`; `Agent execution and fixture checks are admission/context, never numerator outcomes.`; `Incomplete run inventories, expired evidence, incompatible scripts or failed admission remain unknown, not zero conformance.`; `The later staged-safe-output probe and engine-native extensions are not silently folded into the stable five-case series.`; `The separate native Agy host gate is not silently inferred from the shared suite or generic engine success.`

The frozen definitions and formulas are applied to every post-adoption observation. The structured evidence, exact snapshots, provenance, units, and native values are recorded in the adjacent `engine-conformance-agy-timeline.json` artifact.

## Important limitation

This report can show whether the intended outcome is attained after adoption. It cannot estimate change from pre-adoption conditions or attribute attainment to the workflow.
