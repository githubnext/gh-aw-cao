## How to read the timeline

- The measurement contract was activated on `2026-10-19`; this is not a workflow adoption date.
- No historical reference has been established.
- Each dot is one immutable observation. Missing evidence is omitted, never treated as zero.
- Execution activity is diagnostic only. It does not prove repository value.
- Recent change compares the immediately preceding equal-duration period, not lifetime movement. Interval windows must abut without overlap; snapshot values compare cutoff states.
- Two observations show observed change, not a sustained trend, statistical anomaly or target attainment. Unknown coverage, gaps and provisional evidence make comparison unavailable.
- Historical reference comparison is separate. Stable-but-bad outcomes are not healthy merely because their latest delta is zero; workload-mix changes can explain aggregate movement.

## What was measured

**Goal:** Active reporting workflows follow project Markdown conventions and produce clear, decision-useful reports with appropriate progressive disclosure.

**Accepted outcome:** Count content-preserving native report-style repairs only after independent original/revised bytes, edit time and active reporting membership are established. Syntax improvement is partial value, not readability or full goal completion.

### Native style repairs

- **What it tells you:** Independently verified native style-repaired reports. This is a `primary` measure.
- **Native measurement formula:** `Distinct eligible native report subjects with a protected, dated, content-preserving before/after repair of at least one supported source-defined style facet and no facet regression in the disjoint period. Unknown producer/cohort/history => null.`
- **Unit:** `reports`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

## Evidence rules

- **Repository:** `github/gh-aw`
- **Evidence population:** A stable, independently identified issue report of a workflow active in the preceding 24 hours with report-producing safe outputs; native body-edit improvements are delivered once in [windowStart,windowEnd). Comments, Discussions and prompt-guidance edits require additional native decoders and are not silently treated as issues.
- **Collection:** Offline, digest-checked full immutable source closure plus production readOutputHistory discovery. No native report history or protected active-cohort producer was acquired. No network, source execution or per-window Git acquisition.
- **Observation window:** 1 days, sampled every 1 days
- **Maturation delay:** 0 days
- **Filters:** `Current frozen source profile only; do not apply it retrospectively.`; `Activity membership and original output identity need independent protected producer evidence, not editable tracking markers or agent claims.`; `Original and changed report bytes must preserve all non-style content and relative heading hierarchy within the closed supported syntax.`; `Count each underlying report once per interval; repeated references or several repaired facets do not multiply delivery.`; `No facet may regress; unsupported syntax and unverified edit dates are unknown, not clean.`; `Actor independent. Full readability and normalizer contribution are separately unknown.`

The frozen goal, acceptance rule and formulas are applied to every observation. The structured evidence, exact snapshots, provenance, units, and native values are recorded in the adjacent `workflow-normalizer-timeline.json` artifact.

## Important limitation

This report measures accepted repository outcomes against the stated goal. Contract activation is not an intervention or proof that an agent caused the outcomes; unavailable historical evidence supports no historical improvement claim.
