## How to read the timeline

- Observations begin at workflow adoption on `2026-01-22`.
- No comparable pre-adoption evidence is available. Complete adjacent post-adoption periods may still show recent change, but not change relative to adoption.
- Each dot is one immutable observation. Missing evidence is omitted, never treated as zero.
- Execution activity is diagnostic only. It does not prove repository value.
- Recent change compares the immediately preceding equal-duration period, not lifetime movement. Interval windows must abut without overlap; snapshot values compare cutoff states.
- Two observations show observed change, not a sustained trend, statistical anomaly or target attainment. Unknown coverage, gaps and provisional evidence make comparison unavailable.
- Adoption comparison is separate. Stable-but-bad outcomes are not healthy merely because their latest delta is zero; workload-mix changes can explain aggregate movement.

## What was measured

**Goal:** Remove documentation barriers to understanding and adopting gh-aw using Claude Code without Copilot.

**Accepted outcome:** A source-defined concrete Copilot-free Claude setup/auth barrier is demonstrated in original before content and independently resolved in original after content with correctly specified Claude engine selection and required secret setup, verified against contemporaneous immutable implementation or standards. Merely mentioning Claude or increasing example counts is not a repair.

## Evidence rules

- **Repository:** `github/gh-aw`
- **Evidence population:** Immutable before/after change to README.md or the six core documentation paths enumerated by doc-reader.
- **Collection:** Offline original Git custody and complete production issue/PR discovery. Bounded candidate cohort; missing originals and Discussions remain gaps, not zero delivery.
- **Observation window:** 7 days, sampled every 7 days
- **Maturation delay:** 0 days
- **Filters:** `A source-defined concrete Copilot-free Claude setup/auth barrier is demonstrated in original before content and independently resolved in original after content with correctly specified Claude engine selection and required secret setup, verified against contemporaneous immutable implementation or standards. Merely mentioning Claude or increasing example counts is not a repair.`; `Frozen-source fixed-reference predicates can assess historical native facts but cannot establish that later intent was applicable at their time.`

The frozen definitions and formulas are applied to every post-adoption observation. The structured evidence, exact snapshots, provenance, units, and native values are recorded in the adjacent `claude-code-user-docs-review-timeline.json` artifact.

## Important limitation

This report can show whether the intended outcome is attained after adoption. It cannot estimate change from pre-adoption conditions or attribute attainment to the workflow.
