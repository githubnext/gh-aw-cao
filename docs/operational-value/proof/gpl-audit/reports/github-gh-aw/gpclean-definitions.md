- Observations begin at workflow adoption on `2026-02-11`.
- No comparable pre-adoption evidence is available. Complete adjacent post-adoption periods may still show recent change, but not change relative to adoption.
- Each dot is one immutable observation. Missing evidence is omitted, never treated as zero.
- Execution activity is diagnostic only. It does not prove repository value.

## What was measured

**Goal:** Deliver accurate version-bound GPL-family license facts.

**Accepted outcome:** Exact versioned Go module ZIP checksum matches immutable run-head go.sum, and root license terms match independent complete GNU GPL3 terms.

### Corroborated GPL-presence facts

- **What it tells you:** Correct version-bound GPL-presence facts. This is a `primary` measure.
- **Native measurement formula:** `Distinct exact package/version claims independently matching native ZIP checksum and complete GPL3 declaration.`
- **Unit:** `versioned package license facts`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

## Evidence rules

- **Repository:** `github/gh-aw`
- **Evidence population:** A source-goal versioned package license-presence claim.
- **Collection:** Read-only originals acquired separately; offline hash, ZIP and full license-terms replay.
- **Observation window:** 7 days, sampled every 7 days
- **Maturation delay:** 0 days
- **Filters:** `Exact module version, original ZIP, canonical Go directory checksum and immutable Go sum entry.`; `Complete original license terms, not a title substring or current repository license.`; `One package/version fact per original report-creation cohort; no repeated snapshot credit.`

The frozen definitions and formulas are applied to every post-adoption observation. The structured evidence, exact snapshots, provenance, units, and native values are recorded in the adjacent `gpclean-timeline.json` artifact.
