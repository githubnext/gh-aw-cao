## How to read the timeline

- Observations begin at workflow adoption on `2026-03-02`.
- No comparable pre-adoption evidence is available. Complete adjacent post-adoption periods may still show recent change, but not change relative to adoption.
- Each dot is one immutable observation. Missing evidence is omitted, never treated as zero.
- Execution activity is diagnostic only. It does not prove repository value.
- Recent change compares the immediately preceding equal-duration period, not lifetime movement. Interval windows must abut without overlap; snapshot values compare cutoff states.
- Two observations show observed change, not a sustained trend, statistical anomaly or target attainment. Unknown coverage, gaps and provisional evidence make comparison unavailable.
- Adoption comparison is separate. Stable-but-bad outcomes are not healthy merely because their latest delta is zero; workload-mix changes can explain aggregate movement.

## What was measured

**Goal:** Append exactly the next nonduplicate Odyssey line to the source-declared target PR branch.

**Accepted outcome:** Independent, source-bound pre/post target bytes prove one nonduplicate next-line append under a frozen edition/sequence oracle; target identity and branch are preserved.

### Verified sequential appends

- **What it tells you:** Verified next-line appends. This is a `primary` measure.
- **Native measurement formula:** `Count independently bound assessments whose exact-byte append equals the frozen next intended line, with no duplicate or prior-byte alteration.`
- **Unit:** `verified line appends`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

### Structural partial progress

- **What it tells you:** Verified nonduplicate one-line appends. This is a `diagnostic` measure.
- **Native measurement formula:** `Count independently bound exact-byte nonduplicate one-line appends, separately from unknown Odyssey sequence acceptance.`
- **Unit:** `verified line appends`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

## Evidence rules

- **Repository:** `github/gh-aw`
- **Evidence population:** An independently bound update attempt on source-declared PR #1; skipped workflow records are not update opportunities.
- **Collection:** Offline replay of digest-bound public source profiles and complete retained run metadata. Native target receipts are unavailable under public-only authority.
- **Observation window:** 7 days, sampled every 7 days
- **Maturation delay:** 0 days
- **Filters:** `Public-only authority; authenticated access is not permission to collect private target content.`; `Exact immutable source profile determines target; inconsistent namespaces are never silently aliased.`; `No agent text, issue report, job success, PR state or generic push count establishes the outcome.`; `An independently known structural append may count as partial progress without asserting the next intended line.`; `No accepted source-grounded Odyssey edition/sequence oracle exists in the reviewed source closure.`; `Unknown, absent opportunities and failed native assessments remain distinct.`

The frozen definitions and formulas are applied to every post-adoption observation. The structured evidence, exact snapshots, provenance, units, and native values are recorded in the adjacent `smoke-update-cross-repo-pr-timeline.json` artifact.

## Important limitation

This report can show whether the intended outcome is attained after adoption. It cannot estimate change from pre-adoption conditions or attribute attainment to the workflow.
