## How to read the timeline

- Observations begin at workflow adoption on `2026-10-06`.
- No comparable pre-adoption evidence is available. Complete adjacent post-adoption periods may still show recent change, but not change relative to adoption.
- Each dot is one immutable observation. Missing evidence is omitted, never treated as zero.
- Execution activity is diagnostic only. It does not prove repository value.
- Recent change compares the immediately preceding equal-duration period, not lifetime movement. Interval windows must abut without overlap; snapshot values compare cutoff states.
- Two observations show observed change, not a sustained trend, statistical anomaly or target attainment. Unknown coverage, gaps and provisional evidence make comparison unavailable.
- Adoption comparison is separate. Stable-but-bad outcomes are not healthy merely because their latest delta is zero; workload-mix changes can explain aggregate movement.

## What was measured

**Goal:** Detect Copilot Anthropic Messages inference, streaming tool-use and follow-up inference incompatibilities without model fallback.

**Accepted outcome:** The protected host validates an unpredictable MCP receipt and an exactly matching single noop after tool-result inference, with successful execution and disabled fallback in the trusted environment.

### Observed behavioral proofs

- **What it tells you:** Observed independently proven behaviors. This is a `primary` measure.
- **Native measurement formula:** `Count named source-defined host behavioral assertions proven true; unknown components stay unknown.`
- **Unit:** `behavior proofs`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

### Full source-goal acceptance

- **What it tells you:** Fully accepted smoke assessments. This is a `diagnostic` measure.
- **Native measurement formula:** `Count assessments meeting every source-specific goal requirement, only when all acceptance facts are known.`
- **Unit:** `assessments`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

## Evidence rules

- **Repository:** `github/gh-aw`
- **Evidence population:** Named source-defined behavioral assertions per independently observed execution attempt.
- **Collection:** Offline digest-checked replay of bounded immutable-head Actions receipts, reviewed source blobs and trusted mainline lock/runtime trees.
- **Observation window:** 7 days, sampled every 7 days
- **Maturation delay:** 0 days
- **Filters:** `Only exact reviewed host checker scripts and protected environments establish behavioral proof.`; `Run, agent and job success are never behavioral evidence. A failed conjunction has unknown components.`; `Distinct attempts are repeated monitoring assessments, not unique repository improvements.`; `Observed native subtotals survive missing attempts; they are not complete workflow-wide totals.`; `Aider's checker proves two partial facets, not edit method or safe-output publication.`; `Agy requires its actual specialized native gate separately from the shared conformance gate.`

The frozen definitions and formulas are applied to every post-adoption observation. The structured evidence, exact snapshots, provenance, units, and native values are recorded in the adjacent `smoke-claude-copilot-timeline.json` artifact.

## Important limitation

This report can show whether the intended outcome is attained after adoption. It cannot estimate change from pre-adoption conditions or attribute attainment to the workflow.
