## How to read the timeline

- Observations begin at workflow adoption on `2026-02-21`.
- No comparable pre-adoption evidence is available. Complete adjacent post-adoption periods may still show recent change, but not change relative to adoption.
- Each dot is one immutable observation. Missing evidence is omitted, never treated as zero.
- Execution activity is diagnostic only. It does not prove repository value.
- Recent change compares the immediately preceding equal-duration period, not lifetime movement. Interval windows must abut without overlap; snapshot values compare cutoff states.
- Two observations show observed change, not a sustained trend, statistical anomaly or target attainment. Unknown coverage, gaps and provisional evidence make comparison unavailable.
- Adoption comparison is separate. Stable-but-bad outcomes are not healthy merely because their latest delta is zero; workload-mix changes can explain aggregate movement.

## What was measured

**Goal:** Monitor documented workflow editor health and keep preview screenshots up to date.

**Accepted outcome:** Constrained facet only: independently attributable original HTTP GET responses return exactly 200 for each actual standalone documented editor destination at a checkpoint.

### Available documented editors

- **What it tells you:** Available documented editors. This is a `primary` measure.
- **Native measurement formula:** `100 * independently verified HTTP-200 editor responses / all eligible actual editor destinations at the same complete checkpoint`
- **Unit:** `percent`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

## Evidence rules

- **Repository:** `github/gh-aw`
- **Evidence population:** One original HTTP GET per actual documented editor destination in one complete checkpoint.
- **Collection:** Offline batch replay of digest-checked immutable source profiles and preserved original HTTP checkpoints; no API or current probes during evaluation.
- **Observation window:** 7 days, sampled every 7 days
- **Maturation delay:** 0 days
- **Filters:** `Sequential heading-bound standalone URL, LinkButton or standalone Markdown destination.`; `Exclude screenshot image destinations and ancillary prose documentation references; preserve their original responses separately.`; `Match checkpoint inventory revision, exact resolved URL and editor ID; do not follow redirects.`; `Accept independently attributable original HTTP responses or original curl connection failures with separate immutable independently verified probe-environment evidence.`; `Missing instrumentation, unreliable probes and an empty editor population are unavailable, never 100 percent.`

The frozen definitions and formulas are applied to every post-adoption observation. The structured evidence, exact snapshots, provenance, units, and native values are recorded in the adjacent `weekly-editors-health-check-timeline.json` artifact.

## Important limitation

This report can show whether the intended outcome is attained after adoption. It cannot estimate change from pre-adoption conditions or attribute attainment to the workflow.
