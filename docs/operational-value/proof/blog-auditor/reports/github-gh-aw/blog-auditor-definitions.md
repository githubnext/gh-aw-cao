## How to read the timeline

- Observations begin at workflow adoption on `2025-10-22`.
- No comparable pre-adoption evidence is available. Complete adjacent post-adoption periods may still show recent change, but not change relative to adoption.
- Each dot is one immutable observation. Missing evidence is omitted, never treated as zero.
- Execution activity is diagnostic only. It does not prove repository value.
- Recent change compares the immediately preceding equal-duration period, not lifetime movement. Interval windows must abut without overlap; snapshot values compare cutoff states.
- Two observations show observed change, not a sustained trend, statistical anomaly or target attainment. Unknown coverage, gaps and provisional evidence make comparison unavailable.
- Adoption comparison is separate. Stable-but-bad outcomes are not healthy merely because their latest delta is zero; workload-mix changes can explain aggregate movement.

## What was measured

**Goal:** For weekly blog observation opportunities, independently verify the declared page checks and workflow snippets, preserving failures as useful monitoring evidence.

**Accepted outcome:** Protected contemporaneous browser facts reproduce each native assertion; independent pinned compiler receipts establish snippet validation. Agent claims and run conclusions are never evidence.

### Independently assessed page checks

- **What it tells you:** Independently assessed page checks. This is a `primary` measure.
- **Native measurement formula:** `Count known HTTP/domain/length/keyword assertions, at most four per weekly opportunity, including independently verified failures.`
- **Unit:** `checks`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

### Passing page checks

- **What it tells you:** Passing page checks. This is a `diagnostic` measure.
- **Native measurement formula:** `Count true independently assessed page assertions; no assertion about factual freshness.`
- **Unit:** `checks`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

### Independently compiled workflow snippets

- **What it tells you:** Independently compiled workflow snippets. This is a `diagnostic` measure.
- **Native measurement formula:** `Count eligible DOM code blocks with protected native compile receipts, regardless of exit status.`
- **Unit:** `snippets`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

### Schema-valid workflow snippets

- **What it tells you:** Schema-valid workflow snippets. This is a `diagnostic` measure.
- **Native measurement formula:** `Count independently compiled eligible blocks with zero compiler exit code.`
- **Unit:** `snippets`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

### Fully passing explicit-check checkpoints

- **What it tells you:** Fully passing explicit-check checkpoints. This is a `diagnostic` measure.

- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

## Evidence rules

- **Repository:** `github/gh-aw`
- **Evidence population:** One target-page observation per compiled weekly Wednesday 11:26 UTC slot, assigned exclusively by that slot's start to a half-open interval cohort. Manual and independent observations can fill the same slot, never add another copy.
- **Collection:** Offline digest-checked immutable capture archive; shared cursor inventory is discovery only. No APIs, fetched code execution or present-day historical reconstruction.
- **Observation window:** 7 days, sampled every 7 days
- **Maturation delay:** 0 days
- **Filters:** `Exact target URL; weekly slot starts within requested inclusive-start/exclusive-end interval and capture completes before its endpoint.`; `First independently protected capture by actual capture time in each weekly slot, independent of pass/fail and producer.`; `Detailed page predicates: HTTP 200; HTTPS exact allowed hostname without credentials; accessibility snapshot UTF-16 length >5000; case-sensitive GitHub/workflow/compile and agentic-workflows or agentic workflows.`; `Workflow snippets: yaml/yml/markdown/md language hints, root --- frontmatter and a top-level on/engine/tools/permissions/safe-outputs key.`; `Schema compilation is not behavioral correctness; latest schema requires a separate independent release-reference receipt.`

The frozen definitions and formulas are applied to every post-adoption observation. The structured evidence, exact snapshots, provenance, units, and native values are recorded in the adjacent `blog-auditor-timeline.json` artifact.

## Important limitation

This report can show whether the intended outcome is attained after adoption. It cannot estimate change from pre-adoption conditions or attribute attainment to the workflow.
