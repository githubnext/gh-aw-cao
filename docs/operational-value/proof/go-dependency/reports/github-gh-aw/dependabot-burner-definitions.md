## How to read the timeline

- Observations begin at workflow adoption on `2026-01-29`.
- No comparable pre-adoption evidence is available. Complete adjacent post-adoption periods may still show recent change, but not change relative to adoption.
- Each dot is one immutable observation. Missing evidence is omitted, never treated as zero.
- Execution activity is diagnostic only. It does not prove repository value.
- Recent change compares the immediately preceding equal-duration period, not lifetime movement. Interval windows must abut without overlap; snapshot values compare cutoff states.
- Two observations show observed change, not a sustained trend, statistical anomaly or target attainment. Unknown coverage, gaps and provisional evidence make comparison unavailable.
- Adoption comparison is separate. Stable-but-bad outcomes are not healthy merely because their latest delta is zero; workload-mix changes can explain aggregate movement.

## What was measured

**Goal:** Create runtime-and-manifest-specific dependency bundles that enable downstream remediation.

**Accepted outcome:** Original bundle names the target and versions for one Go runtime/root manifest; independent actual-merge/first-parent go.mod pins advance to those exact versions. This is the older issue-bundler goal, not current generated-source remediation.

### Bundled dependency targets implemented

- **What it tells you:** Bundled dependency targets implemented. This is a `primary` measure.
- **Native measurement formula:** `Sum independently verified native partial deliveries in evaluated retained cases within this disjoint interval; null when no eligible retained case was evaluated.`
- **Unit:** `bundled dependency targets implemented`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

### Corroborated shared workflow contribution

- **What it tells you:** Corroborated shared workflow contribution. This is a `diagnostic` measure.
- **Native measurement formula:** `The same native deliveries restricted to original recommendation and implementation-reference matches; shared contribution, not sole causation.`
- **Unit:** `bundled dependency targets implemented`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

## Evidence rules

- **Repository:** `github/gh-aw`
- **Evidence population:** Seven explicitly recommended Go module targets across two retained February bundle implementations; other selected candidates remain unassessed, not zero.
- **Collection:** Offline replay of digest-checked original Git commits, trees and source blobs plus bounded public GitHub originals; no target code or network execution.
- **Observation window:** 7 days, sampled every 7 days
- **Maturation delay:** 0 days
- **Filters:** `Retrospective fixed-reference and selected-case assessment; not complete historical repository or workflow output coverage.`; `Immutable actual merge/first-parent source transitions only; one opportunity is counted in one interval.`; `Periods without evaluated eligible cases are unknown, never zero workflow delivery.`; `Original strict acceptance, behavior safeguards, historical executor continuity and authoritative creation receipts remain separate.`

The frozen definitions and formulas are applied to every post-adoption observation. The structured evidence, exact snapshots, provenance, units, and native values are recorded in the adjacent `dependabot-burner-timeline.json` artifact.

## Important limitation

This report can show whether the intended outcome is attained after adoption. It cannot estimate change from pre-adoption conditions or attribute attainment to the workflow.
