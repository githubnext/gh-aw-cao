## What was measured

**Goal:** Make CLI commands consistent, well documented and free of user-facing defects.

**Accepted outcome:** A source-defined literal documentation obligation is attained exactly when its Contains/NotContains predicate, with the original source scope, holds on the immutable CLI documentation bytes.

### Literal documentation conformance

- **What it tells you:** Native literal documentation obligation attainment. This is a `primary` measure.
- **Native measurement formula:** `100 * passed frozen literal source-defined documentation obligations / all frozen literal source-defined documentation obligations`
- **Unit:** `percent of literal documentation obligations`
- **Goal:** Higher values are better.
- **Chart display:** The chart shows the native value directly on a metric-specific axis.

## Evidence rules

- **Repository:** `github/gh-aw`
- **Evidence population:** Every literal string Contains/NotContains assertion over text, compileSection or updateSection in these source-native tests.
- **Collection:** Digest-checked complete immutable documentation and native tests from the offline source archive. Reinterpret raw native bytes, never caller-supplied acceptance counts. No remote collection.
- **Observation window:** 1 days, sampled every 1 days
- **Maturation delay:** 0 days
- **Filters:** `Engine-registry-dependent assertion remains inventoried and unavailable; not silently classified as clean.`; `compileSection and updateSection intentionally retain the original tests' suffix-of-document semantics, not a narrowed heading section.`; `Current frozen profile only. Historical profiles are not retroactively interpreted as this profile.`

The frozen goal, acceptance rule and formulas are applied to every observation. The structured evidence, exact snapshots, provenance, units, and native values are recorded in the adjacent `cli-consistency-checker-timeline.json` artifact.

## Important limitation

This report measures accepted repository outcomes against the stated goal. Contract activation is not an intervention or proof that an agent caused the outcomes; unavailable historical evidence supports no historical improvement claim.
