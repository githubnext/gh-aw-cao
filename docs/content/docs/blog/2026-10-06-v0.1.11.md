CAO [v0.1.11](https://github.com/githubnext/gh-aw-cao/releases/tag/v0.1.11) is out as a pre-release. It changes how the dashboard handles version updates, makes campaign run outcomes and operational-value charts easier to read correctly, and fixes a collection failure in CAO Activity caused by a newer `gh-aw` JSONL schema version.

## You control when the dashboard reloads

Previously, when a new dashboard build was ready, the page reloaded on its own. In [#16541](https://github.com/githubnext/gh-aw-cao/pull/16541), that automatic reload is replaced with a persistent notification offering **Update now** or **Dismiss**, so an update in progress isn't interrupted by a refresh you didn't ask for. The footer also now shows both the CAO version and the pinned `gh-aw` engine version next to the existing commit hash ([#16542](https://github.com/githubnext/gh-aw-cao/pull/16542)), so you can tell at a glance which build you're looking at.

## Campaign run outcomes and operational-value charts are easier to read correctly

Several dashboard changes target chart readability and correctness this release:

- Tooltips near a screen edge previously could run off-screen. They now clamp within the viewport and flip above the trigger when there isn't room below, re-measuring on pointer entry, focus, scroll, and resize ([#16554](https://github.com/githubnext/gh-aw-cao/pull/16554)).
- Campaign run-outcome charts use thicker, theme-aware segments below the x-axis — solid for successful runs, hollow for other concluded runs — and the Operational Value page gains a pie chart summarizing concluded outcomes ([#16563](https://github.com/githubnext/gh-aw-cao/pull/16563), [#16564](https://github.com/githubnext/gh-aw-cao/pull/16564)). As the chart's own description notes, run success and produced outputs don't by themselves verify accepted outcomes or operational value — the chart shows concluded-run status, not acceptance.
- Operational-value charts previously plotted the change between consecutive AI-Credit-per-run observations, which could show negative values and an incorrect `/day` label for a per-run metric. [#16565](https://github.com/githubnext/gh-aw-cao/pull/16565) plots each observation in its native per-run unit instead.
- On hover or focus, a point on an operational-value chart now offers a **View run report** link directly in the tooltip ([#16572](https://github.com/githubnext/gh-aw-cao/pull/16572)), so you can jump from a chart point to the run that produced it.

## CAO Activity accepts gh-aw's newer JSONL schema

CAO Activity previously rejected JSONL records using `gh-aw` schema version 4, breaking collection for repositories running a newer `gh-aw` release. [#16539](https://github.com/githubnext/gh-aw-cao/pull/16539) adds version 4 to an explicit schema-version allowlist shared by the string, binary, streaming, and Activity run readers, so mixed-version shards are accepted while canonical ingestion still rejects genuinely unknown versions. The same change stops CAO's CLI from dumping its full command reference on every error, so the actual failure is easier to spot.

## Smaller fixes

- The dashboard no longer flashes the wrong background color before JavaScript loads: an inline stylesheet now paints the correct light/dark tokens up front, honoring the system color-scheme preference ([#16562](https://github.com/githubnext/gh-aw-cao/pull/16562)).
- Large activity imports now reserve visible progress for final stages — retention, inventory preparation, query refresh — instead of appearing nearly complete while still working ([#16568](https://github.com/githubnext/gh-aw-cao/pull/16568)).

## What to do next

If you run CAO Activity collection against a repository using a newer `gh-aw` release, update to this CAO runtime so schema version 4 records are accepted. Dashboard operators don't need to do anything to adopt the update-notification or chart changes — they apply automatically on next load, at which point you'll see the **Update now** prompt described above instead of an automatic refresh. Read the full [release notes](https://github.com/githubnext/gh-aw-cao/releases/tag/v0.1.11) for the complete change list, including [#16524](https://github.com/githubnext/gh-aw-cao/pull/16524) and [#16523](https://github.com/githubnext/gh-aw-cao/pull/16523).
