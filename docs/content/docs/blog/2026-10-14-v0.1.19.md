CAO [v0.1.19](https://github.com/githubnext/gh-aw-cao/releases/tag/v0.1.19) is a stable release, not a pre-release. The comparison from v0.1.18 contains one commit, [#17952](https://github.com/githubnext/gh-aw-cao/pull/17952) (commit `5a7695bdd`), which upgrades the toolchain and dependencies of the packaged CAO server.

## A newer Go toolchain for the server

`server/go.mod` now targets Go 1.27.2 instead of 1.27.1, and `server/Dockerfile` builds from a `golang:1.27.2-alpine` image pinned by digest instead of the floating `golang:1.27-alpine` tag. If you build the server image yourself, it now uses a fixed Go patch version.

The same bump is applied across the repository's CI workflows, including `.github/workflows/cgo.yml` and `.github/workflows/cao-package.yml`, and in the Azure deployment prerequisites in [`docs/deployment-azure.md`](https://github.com/githubnext/gh-aw-cao/blob/v0.1.19/docs/deployment-azure.md).

## Updated Go modules

In `server/go.mod`, the indirect dependencies `golang.org/x/net`, `golang.org/x/sync`, `golang.org/x/sys`, and `golang.org/x/text` move to newer versions (for example, `x/net` from v0.58.0 to v0.60.0). The commit message says the purpose is to fix release vulnerabilities and to retain the blocking Trivy and Grype release gates. I did not verify which specific advisories were addressed, so this post doesn't name any.

## Lint tooling

golangci-lint moves from v2.13.2 to v2.14.0 in `.github/workflows/cgo.yml`, `.github/workflows/copilot-setup-steps.yml`, and [`server/README.md`](https://github.com/githubnext/gh-aw-cao/blob/v0.1.19/server/README.md). In `server/internal/server/server.go`, two `#nosec G703` annotations now record that file paths are constrained to the configured site directory. The diff shows annotations only, not a change in how paths are handled.

## What to do next

If you install or update CAO with `gh aw add` or `gh aw update`, no configuration change is needed based on the evidence reviewed. If you build or run the CAO server from source or from its Dockerfile, rebuild with Go 1.27.2 and review the [v0.1.19 release page](https://github.com/githubnext/gh-aw-cao/releases/tag/v0.1.19). The evidence doesn't show changes to campaign or dashboard behavior.
