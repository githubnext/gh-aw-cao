CAO [v0.1.13](https://github.com/githubnext/gh-aw-cao/releases/tag/v0.1.13) is out as a pre-release. It gives dashboard actions one consistent safety model across CLI commands and generated prompts, adds raw and table views for repository-memory files, and upgrades the control plane's underlying `gh-aw` engine to v0.91.5.

## Dashboard actions now share one safety model

Previously, dashboard actions were defined two different ways depending on whether they ran as a CLI command or a generated prompt, which tied their safety boundary to how they happened to execute. [#16661](https://github.com/githubnext/gh-aw-cao/pull/16661) replaces that with a single typed representation covering declared CLI actions, row actions, and synthesized view prompts. Every action now carries one of four explicit levels — `ui`, `explore`, `propose`, or `operate` — defined in `dashboard/site/src/action-model.js`, with a validator that rejects invalid levels and refuses to let a mutating CLI command declare itself read-only (`explore`). Explore prompts carry a read-only constraint, proposals preview the request before it runs, and operate-level actions show the underlying command and require explicit confirmation. Action labels and icons are level-based, stay visible on narrow screens, and get distinguishing screen-reader labels by view.

## Repository-memory files get a table view

Repository-memory JSONL files were previously readable only as formatted raw text, which made it hard to compare records side by side. [#16662](https://github.com/githubnext/gh-aw-cao/pull/16662) adds Raw and Table tabs to both the all-campaign Memory page and individual campaign memory browsers, implemented in the new `dashboard/site/src/components/memory-file-content.js`. Table preparation happens in the data worker rather than the main thread, reusing the existing table's sorting, filtering, and load-more controls; switching tabs preserves your sort and filter state. Top-level JSONL fields become columns with physical line numbers retained, nested values stay as JSON text, and malformed records surface an explicit table error while remaining readable in Raw.

## gh-aw engine upgraded to v0.91.5

[#16663](https://github.com/githubnext/gh-aw-cao/pull/16663) upgrades the compiler and runtime from `gh-aw` v0.91.1 to v0.91.5, regenerating all 71 workflow lock files. The new compiler forbids `post-steps` from reading safe-output storage directly, so this PR also migrates bounded dispatcher telemetry to `safe-outputs.steps`, gated to the consolidated orchestrator job to avoid duplicate spans; invalid evidence now produces a visible, nonblocking step failure instead of a silently empty success. No optional new capability was enabled as part of this upgrade.

## Smaller fixes

- `terminateProcessTree` in the operational-value collector gained a pure, independently testable `classifyProcessGroupKillError` helper and a disabled-by-default `cao:operationalvalue:processtree` debug logger that records only the PID when a process-group kill fails for a reason other than "already exited." Public return behavior is unchanged ([#16659](https://github.com/githubnext/gh-aw-cao/pull/16659)).
- `dashboard/site/src/view-filter-validator.js` gained category-filtered debug logging (`view-filter-validator`) at its filter-bar rejection and validation-completion points, closing a gap where a rejected or passing filter-bar validation previously produced no observable signal ([#16660](https://github.com/githubnext/gh-aw-cao/pull/16660)).

## What to do next

Control-plane operators don't need to take any action to adopt this release — the dashboard action levels and memory table views apply automatically on next load. If you maintain custom dashboard view JSON with CLI or prompt actions, review [#16661](https://github.com/githubnext/gh-aw-cao/pull/16661) for the level field now required on each action. Read the full [release notes](https://github.com/githubnext/gh-aw-cao/releases/tag/v0.1.13) for the complete change list, including the `gh-aw` v0.91.5 upgrade details in [#16663](https://github.com/githubnext/gh-aw-cao/pull/16663).
